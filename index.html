Aturan Ukuran PDF Administrasi di Indonesia

Setiap instansi pemerintah dan pendidikan memiliki batas maksimal upload yang berbeda. KARYA ABDI PDF membantu Anda menyesuaikan ukuran file dengan cepat.

CPNS & BUMN (BKN)
Maks 200 KB

Sistem ASN-LKBN (BKN) umumnya membatasi unggah ijazah dan transkrip maksimal 200 KB per file. Gunakan kompresi maksimal jika berisi scan.

PPDB Sekolah
Maks 500 KB

Sistem PPDB online di berbagai daerah membatasi ukuran dokumen pendukung (KK, Akta) maksimal 500 KB hingga 1 MB.

LPSE & Pengadaan Barang
Maks 1 MB

Dokumen persyaratan lelang SPSE (LPSE) seringkali dibatasi maksimal 1 MB per file. Aktifkan mode "Jangan melebihi target".

Beasiswa LPDP
Maks 2 MB

Aplikasi Beasiswa LPDP memperbolehkan ukuran dokumen (ijazah, transkrip, rekomendasi) hingga 2 MB per file.

Fitur Utama Karya Abadi PDF

Karya Abadi PDF dirancang dengan teknologi canggih untuk memastikan setiap file PDF Anda terkompresi secara presisi sesuai target administrasi yang diinginkan tanpa mengorbankan privasi data.

Target Ukuran Presisi

Pengguna dapat menentukan target ukuran file secara spesifik, mulai dari 200 KB, 500 KB, 1 MB, hingga 2 MB. Fitur ini memastikan dokumen Anda diterima oleh sistem administrasi pemerintah yang memiliki batasan teknis ketat tanpa risiko penolakan otomatis akibat ukuran berkas yang melebihi batas maksimal yang ditentukan oleh persyaratan sistem.

Algoritma Binary Search

Tool ini menggunakan algoritma iteratif binary search yang secara cerdas mencari tingkat kualitas gambar JPEG dan skala DPI terbaik. Sistem tidak hanya melakukan kompresi sekali, melainkan mencari parameter optimal secara bertahap agar hasil akhir sedekat mungkin dengan target ukuran yang Anda inginkan tanpa merusak struktur halaman dokumen PDF tersebut.

100% Privat & Client-Side

Privasi data adalah prioritas utama. Seluruh proses kompresi dilakukan sepenuhnya secara client-side di dalam browser Anda. Tidak ada satu pun file PDF yang diunggah ke server eksternal, sehingga menjamin keamanan data sensitif seperti ijazah, transkrip nilai, atau dokumen kependudukan Anda dari risiko kebocoran data di dunia digital.

Mode Kualitas Fleksibel

Tersedia tiga mode kualitas kompresi: Tinggi untuk dokumen resmi yang membutuhkan ketajaman teks, Seimbang untuk kompromi terbaik antara ukuran dan kualitas, serta Kompres Maksimal untuk memprioritaskan reduksi ukuran file. Target ukuran tetap menjadi prioritas utama di seluruh mode kualitas yang Anda pilih untuk menjaga kepatuhan administrasi.

Preset Aturan Administrasi

Tersedia tombol pintasan (preset) untuk aturan CPNS, BUMN, PPDB, LPSE, dan LPDP. Tombol ini secara otomatis mengatur target ukuran sesuai dengan batasan umum yang diterapkan oleh sistem ASN-LKBN, SPSE, dan portal beasiswa, sehingga Anda tidak perlu repot mencari informasi batas maksimal upload file secara manual.

Fitur Jangan Melebihi Target

Fitur toggle ini memastikan bahwa file hasil kompresi tidak akan pernah melampaui batas target yang ditentukan. Jika target 1 MB, hasil kompresi dijamin berada di angka 999 KB atau lebih kecil. Hal ini sangat esensial untuk pendaftaran CPNS, LPSE, maupun PPDB di mana sistem akan otomatis menolak file yang melebihi batas ukuran yang telah ditetapkan.

Panduan Penggunaan Tool

Ikuti langkah-langkah berikut untuk mengompres file PDF Anda sesuai dengan target ukuran yang diinginkan secara cepat dan akurat tanpa memerlukan instalasi software tambahan.

1. Upload File PDF

Klik tombol "Jelajahi File" atau seret dan lepas file PDF Anda langsung ke area upload. Pastikan file berformat PDF valid dan tidak melebihi batas maksimal 100 MB untuk memastikan proses kompresi berjalan lancar di browser Anda tanpa mengalami gangguan memori atau crash pada perangkat.

2. Pilih Target Ukuran

Pilih target ukuran file yang Anda inginkan, seperti 500 KB atau 1 MB. Anda juga dapat menggunakan tombol pintasan preset seperti CPNS/BUMN atau LPSE untuk menyesuaikan batasan ukuran spesifik dari instansi pemerintah. Jika memiliki target custom, pilih "Ukuran Bebas" dan masukkan angka beserta satuan KB atau MB.

3. Atur Batas & Kualitas

Aktifkan toggle "Jangan melebihi target" untuk menjamin file hasil kompresi tidak melebihi batas yang telah ditentukan. Pilih mode kualitas (Tinggi, Seimbang, atau Kompres Maksimal) sesuai dengan kebutuhan dokumen Anda. Mode Seimbang sangat direkomendasikan untuk dokumen administrasi umum yang membutuhkan keterbacaan teks dan gambar yang jelas.

4. Kompres & Download

Klik tombol "KOMPRES PDF" dan tunggu proses algoritma binary search mencari tingkat kompresi terbaik. Setelah selesai, detail hasil akan ditampilkan termasuk ukuran asli, target, ukuran hasil, dan persentase pengurangan. Klik tombol "DOWNLOAD PDF" untuk menyimpan file yang sudah dikompres secara aman ke perangkat Anda tanpa watermark.
